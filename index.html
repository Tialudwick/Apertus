1. Core Design Philosophy & Cost Model

This web application was engineered specifically to modernize MARR's web presence with zero ongoing software licensing costs. By building with clean native Web standards (HTML5, Tailwind CSS, Vanilla JS), the platform runs with zero server subscription overhead while providing instant loading times on mobile devices.

Zero PHI & Public Access

Public users, individuals in crisis, and case managers can query real-time recovery bed availability without creating an account or inputting Personal Health Information (PHI). Standby hold requests require only minimal contact details.

7-Day Rolling Window Integrity

Residences automatically transition from Green (<48 hrs) to Yellow (2-7 days) to Red Alert (>7 days) based on timestamp freshness. House managers can reset their window in one tap.

House Manager 30-Second Bed Update Routine

Follow these simple steps every week or whenever bed availability changes.

  1. Access the Manager Portal: Click on House Manager Portal in the top navigation menu.
  2. Select Your Residence: Pick your home name from the dropdown list.
  3. If Bed Count Changed: Tap the large + or - buttons to set your current open beds.
  4. If Bed Count is Unchanged: Click the green Confirm Availability (No Change Needed) button. Your listing freshness resets to Green instantly!
